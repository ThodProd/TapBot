# TapBot

TapBot — плавающие кнопки для автоматизации касаний на Android.

## Что изменено
- targetSdk 30 сохранён.
- OCR больше не запускается в фоне.
- Автопоиск выполняется только после нажатия на OCR-кнопку.
- Сначала используется быстрый поиск текста через Accessibility без скриншота и OCR-библиотеки.
- Если приложение не отдаёт текст в Accessibility, используется одноразовый ML Kit OCR.
- Одна кнопка может содержать несколько слов, у каждого слова свой сценарий.
- Добавлено действие «Найти другое слово» с новым поиском и новой координатой.
- Убрана постоянная проверка OCR, глобальный таймер OCR и старая глобальная область поиска.
- Упрощены меню и русский текст.
- Позиция обычной кнопки после создания берётся из первой выбранной точки.
- Позиции кнопок ограничиваются экраном, чтобы они не уезжали за края.
- Для поиска текста включён доступ к содержимому окна Accessibility.
- Добавлен GitHub Actions для сборки `app-debug.apk`.

## Сборка
GitHub Actions → `Сборка APK` → последний запуск → Artifacts → `TapBot-debug`.
